纪检监察在线考试 · 原生小程序版

code/exam-miniprogram — H5 考生端的原生微信小程序复刻版（纯 WXML/WXSS/JS，无 uni-app/taro）

项目简介

本项目是「纪检监察人员在线考试系统」考生端的原生微信小程序实现，功能与 H5 考生端（code/exam-h5-web）对齐：工号登录、首次强制改密、在线学习（图文/视频/PDF 资料、学习心跳与断点续学）、学习任务、在线考试（答题卡、倒计时服务端校时、答案暂存与断网本地队列、切屏上报、幂等交卷）、日常练习（按法规分类/全库随机抽题、即时判分与解析、练习记录与错题回顾、练习统计）、成绩查询、我的成绩、学习统计、站内信。

微信开发者工具导入步骤

  1. 打开微信开发者工具，选择「导入项目」。
  2. 项目目录选择 code/exam-miniprogram。
  3. AppID 已配置为 touristappid（测试号），可直接导入；也可填入自己的小程序 AppID。
  4. 开发期已通过 project.config.json 的 urlCheck:false 关闭域名校验，可直连内网后端 http://10.110.10.160:8088。
  5. 编译运行后先进入登录页，测试考生账号：ks001 / Exam@123。
正式发布前需在微信公众平台「开发管理 → 开发设置 → 服务器域名」配置 request 合法域名与 downloadFile 合法域名（资料文件 wx.downloadFile / wx.openDocument 使用）；tabBar 当前为纯文字占位，需补充正式图标资源。

页面清单（pages/ 下 17 个页面）

  • login 登录（工号+密码，terminal=MP，mustChangePassword 跳改密）
  • change-password 首次强制改密（PUT /auth/password）
  • learn 学习首页（tabBar）：分类筛选 + 资料列表
  • learn-tasks 学习任务（TODO/DONE 筛选）
  • material-detail 资料详情（rich-text 图文 / 视频 / PDF wx.openDocument + 学习心跳 + 断点续学）
  • exam 考试列表（tabBar，type=TODO/HISTORY）
  • exam-notice 考前须知确认（POST /app/exams/{id}/enter）
  • exam-answer 在线答题（四种题型、答题卡、倒计时校时、暂存、切屏上报、幂等交卷）
  • exam-result 成绩结果（未发布 30s 轮询）
  • practice 日常练习发起页（tabBar，/app/practice/banks 分类 + /app/practice/start）
  • practice-answer 练习答题（一题一页，/app/practice/answer 即时判分 + 解析 + 小结）
  • practice-records 练习记录（/app/practice/records，只看错题含解析）
  • practice-stat 练习统计（/app/practice/stat，按法规正确率 + 薄弱知识点）
  • mine 我的（tabBar：用户信息、入口、退出登录）
  • my-scores 我的成绩（/app/stat/my-transcripts）
  • learn-stat 学习统计（/app/lstat/personal）
  • notices 站内信（/app/notices，支持标记已读/全部已读）

接口配置说明

统一封装在 utils/request.js：

  • API base：http://10.110.10.160:8088/api/v1
  • 统一响应 {code, message, data}，code=0 成功，业务错误统一 toast
  • JWT 认证：请求头 Authorization: Bearer <accessToken>
  • HTTP 401 / code 10002：refreshToken 静默刷新并重放原请求，失败回登录页
  • code 10010：被踢下线，弹窗提示后回登录页
  • __silent 选项支持静默请求（心跳/暂存/校时等不打扰用户）
