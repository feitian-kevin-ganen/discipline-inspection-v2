3. **V1.1 修订要点**（各设计文档修订时须覆盖）：微信小程序为主要用户端（原生 + H5 套壳）、三集团四类人员与角色分组、本期正式考试仅单选（20 题 × 5 分 = 100 分）并预留多题型扩展、新增日常练习模块（FR-PRAC）、题库按 10 部制度法规分类且难度为基础/进阶两级、双重随机组卷、默认限时 30 分钟、提交即时出分、考后答题回顾、个人排名规则（分数降序/同分用时升序）与成绩趋势、微信消息通知通道（FR-NOTIFY-WX）、小程序生态与多组织数据权限非功能需求。

## Harness 思想落地说明

本系统设计采用 Harness 流水线式工程思想（Pipeline–Stage–Step）：

1. **业务全生命周期即流水线**：学习 → 日常练习 → 题库建设 → 组卷 → 下发 → 考试 → 判分 → 阅卷 → 统计，各环节为独立 Stage，Stage 内由可插拔 Step 组成（如判分流水线：客观题判分 → 填空复核 → 主观分合成 → 等级评定；通知流水线：触发事件 → 通道选择（微信/站内信） → 发送 → 留痕兜底）。
2. **声明式配置**：抽题策略（题型/法规范围/难度配比/题量分值）、等级规则、分数段、防作弊阈值、考试时长（默认 30 分钟）、提醒提前量等均声明式配置，调整不改代码。
3. **组件化可插拔**：后端按业务域拆分模块，Step 级扩展点（判分器、统计口径、通知渠道——微信订阅消息/公众号服务通知/站内信可插拔替换）可插拔替换；题型判分器按五题型预留，本期仅启用单选。
4. **自动化驱动**：自动判分即时出分、统计预聚合、定时任务（到时收卷、考前/截止提醒、成绩发布推送）由调度流水线自动执行，关键节点审计留痕。

具体落地设计见《01-概要设计说明书》第 2、5 章及《02-详细设计说明书》判分流水线章节（V1.1 修订时增补练习与微信通知流水线设计）。
