三、学习资料说明
-----------------------------------------------------------
1. 格式：每部法规同时提供 HTML 和 PDF 两种格式
   - HTML：可在浏览器中在线浏览，适合在线学习场景
   - PDF：适合打印或离线阅读

2. 内容：每部法规资料包含
   - 法规名称、发布机关、施行日期等基本信息
   - 核心条款摘要（精选关键知识点，覆盖考试重点）
   - 法规原文来源链接

3. 法规清单（11部）：
   (1) 纪检监察机关处理检举控告工作规则
   (2) 中国共产党纪律处分条例
   (3) 中国共产党问责条例
   (4) 中华人民共和国公职人员政务处分法
   (5) 中华人民共和国监察法
   (6) 中华人民共和国监察法实施条例
   (7) 中国共产党党内监督条例
   (8) 中国共产党纪律检查机关监督执纪工作规则
   (9) 中国共产党廉洁自律准则
   (10) 国有企业领导人员廉洁从业若干规定
   (11) 国有企业执行八项规定相关文件汇编


四、考试题库说明
-----------------------------------------------------------
1. 题量：共10套试卷，每套22题

2. 题型分布（每套100分）：
   - 单选题：10题 × 3分 = 30分
   - 多选题：5题 × 4分 = 20分
   - 填空题：5题 × 4分 = 20分
   - 问答题：2题 × 15分 = 30分

3. 试卷覆盖范围：
   第1套：纪律处分条例 + 廉洁自律准则
   第2套：监察法 + 监察法实施条例
   第3套：政务处分法
   第4套：问责条例 + 党内监督条例
   第5套：监督执纪工作规则 + 检举控告工作规则
   第6套：国有企业廉洁从业规定 + 八项规定
   第7套：纪律处分条例（政治纪律、组织纪律）
   第8套：纪律处分条例（廉洁、群众、工作、生活纪律）
   第9套：综合卷（监察法 + 政务处分法 + 问责条例）
   第10套：综合模拟卷（覆盖全部11部法规）

4. 答案与解析：
   每道题均附有【答案】和【解析】（问答题为【参考答案】和【要点提示】），
   便于学习培训和阅卷参考。

5. 考试建议时间：90分钟/套


五、使用建议
-----------------------------------------------------------
1. 学习阶段：先通读01_学习资料中的HTML/PDF文件，掌握法规核心条款
2. 练习阶段：按专项顺序完成第1-8套试卷，巩固各法规知识点
3. 综合复习：完成第9-10套综合卷，检验整体掌握程度
4. 考试实施：可从中随机选取试卷用于正式考试
