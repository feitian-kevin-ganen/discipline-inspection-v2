## 1. 引言

### 1.1 编写背景

为进一步加强纪检干部队伍建设，提升纪检人员业务能力和政策法规水平，推动纪检工作规范化、法治化、正规化，集团拟建设"纪检人员考试培训"平台，以微信小程序为主要用户载体，覆盖"集团总部 → 二级集团 → 子企业"多级组织，对国联集团、国发集团、机场集团各级纪检人员开展在线学习、日常练习与季度考试相结合的常态化教育培训与考核，实现以考促学、以学促用的闭环管理。

### 1.2 编写目的

本文档描述在线考试系统的全部用户需求，作为后续概要设计、详细设计、数据库设计、接口设计、开发实现与验收测试的依据。

### 1.3 适用范围

- 使用单位：国联集团、国发集团、机场集团总部纪检监察部门，及其下属各二级集团、各级子企业的纪检监察机构。
- 服务对象（考生）：上述三个集团的以下四类人员——
  1. 派驻组全体人员；
  2. 各子企业纪委工作人员；
  3. 各基层党组织纪检委员；
  4. 其他从事或参与纪检相关工作的人员。
- 使用人员：集团总部管理员、二级集团管理员、子企业管理员、上述四类纪检监察人员（考生）、阅卷人员。

### 1.4 术语定义

| 术语 | 说明 |
| --- | --- |
| 大集团/总部 | 集团总部层级，组织架构树的根节点（本期为国联集团、国发集团、机场集团各自的总部） |
| 二级集团 | 总部直接下属的产业集团/事业部层级 |
| 子企业 | 二级集团（或更低层级单位）下属的企业单位，层级可向下延伸 |
| 考生 | 被纳入考试范围的纪检监察人员（派驻组人员、子企业纪委工作人员、纪检委员及其他纪检相关人员） |
| 角色分组 | 按派驻组 / 子企业纪委 / 纪检委员等身份对考生进行的分组 |
| 原生小程序 | 基于微信小程序原生框架开发的用户端 |
| H5 套壳小程序 | 以小程序 web-view 承载 H5 页面的用户端形态 |
| 场次 | 一次具体安排的考试活动（含试卷、时间、人员范围） |
| 固定卷 | 所有考生使用同一份试卷 |
| 随机卷 | 按抽题策略从题库随机组卷，考生试卷各不相同 |
| 双重随机 | 随机组卷基础上，每位考生的题目顺序与选项顺序均随机打乱 |
| 日常练习 | 考生随时自主进行的非正式刷题，不受考试时间限制 |
| 等级 | 按分数段划分的成绩等级（优、良、中、差），可配置 |

## 2. 项目概述

### 2.1 建设目标

建设覆盖"学、练、考、评、统"全生命周期的在线考试平台，以微信小程序为主要用户入口：

1. **组织到人**：维护三集团多级组织架构与纪检人员信息，按派驻组/子企业纪委/纪检委员等角色分组管理，支持按层级授权管理。
2. **学习在线化**：学习资料在线发布、在线学习、学习过程留痕（平台既有能力）。
3. **练习常态化**：考生可随时自主刷题，按制度法规分类练习或全库随机抽题，即时显示答案与解析，练习记录留存。
4. **考试全流程在线化**：按 11 部制度法规建设题库，每季度组织一次正式考试，随机抽题组卷（题序、选项双重随机）、在线答题、提交自动判分即时出分、考后答题回顾。
5. **统计分层级**：按组织层级汇总考试结果，支持分数段分布、优良中差等级统计、个人排名与横向对比。
6. **通知移动化**：考试发布、考前/截止提醒、成绩公布通过微信消息通道精准推送。

### 2.2 用户角色

| 角色 | 说明 | 主要功能 |
| --- | --- | --- |
| 超级管理员 | 系统运维方/总部最高权限 | 系统参数、全部数据、账号管理 |
| 总部管理员 | 集团总部纪检监察部门管理员 | 全集团组织、人员、题库、考试、统计、通知发布 |
| 二级管理员 | 二级集团管理员 | 本集团及下属子企业的组织、人员、考试组织、统计查看 |
| 子企业管理员 | 子企业管理员 | 本单位人员维护、学习/考试组织、本单位统计 |
| 阅卷教师 | 指定的主观题阅卷人员（平台既有能力，本期正式考试无主观题） | 主观题评阅 |
| 考生（纪检人员） | 派驻组人员、子企业纪委工作人员、基层党组织纪检委员及其他纪检相关人员 | 在线学习、日常练习、在线考试、查看本人成绩与排名 |

### 2.3 用户端载体形态（V1.1 调整）

| 载体 | 定位 | 说明 |
| --- | --- | --- |
| 微信小程序（原生） | **主要用户端** | 考生的默认入口：日常练习、在线考试、成绩查询、消息订阅均在原生小程序完成 |
| 微信小程序（H5 套壳） | 主要用户端的补充形态 | 以小程序 web-view 承载现有 H5 页面，用于快速复用 H5 功能与灰度过渡 |
| PC 管理端 | 管理端（保留） | 管理员使用的 Web 后台：组织人员、题库、试卷、考试、统计、系统管理 |
| PC 用户端 / 手机 H5 | 可选访问渠道（降级） | 保留既有 H5/PC 答题能力，作为小程序之外的兼容与兜底访问方式，非本期主要建设对象 |

### 2.4 业务全景与全生命周期流程

```
组织与人员初始化（含角色分组） → 学习资料建设与发布 → 纪检人员在线学习 → 学习统计（时长/内容/完成度）
      → 题库建设（11 部制度法规分类、来源/章节/知识点标注、难度标记、Excel 批量导入）
      → 日常练习（随时自主练习、分类刷题、随机抽题、即时解析、练习记录）
      → 试卷设计（本期：单选 20 题×5 分=100 分；固定/随机组卷、分数设计）
      → 考试场次创建（每季度一次、按单部或多部法规出题、限时 10 分钟可配）与考题下发
      → 微信通知（发布推送、考前/截止提醒） → 在线考试（倒计时、双重随机、防作弊、断线续考）
      → 自动判分即时出分（+ 主观题阅卷，平台既有能力） → 成绩发布、微信推送与等级评定
      → 分层级统计分析（分数段、优良中差、个人排名、单位排名、成绩导出） → 结果归档与补考/复训（闭环）
```

### 2.5 系统边界

- 系统内：组织人员管理（含角色分组）、学习管理、日常练习、题库/试卷/考试管理、判分阅卷、统计分析、微信/站内通知、系统管理。
- 系统外（仅预留对接）：统一身份认证（SSO）、微信开放平台（小程序登录、订阅消息、公众号服务通知）、短信通知、集团 HR 组织主数据同步。本期以系统内功能与微信生态对接为主，其余对接以接口预留方式实现。

| FR-ORG-02 | 每个组织节点维护：单位名称、单位编码（唯一）、单位类型（总部/二级集团/子企业/部门）、上级单位、负责人、联系电话、排序号、状态。 | P0 |
| FR-ORG-03 | 人员管理：维护纪检人员姓名、工号（唯一）、手机号、性别、所属单位、岗位职务、联系方式、角色、账号状态。人员归属单位变更时保留其历史学习、练习与考试记录（记录按当时单位快照留存）。 | P0 |

| FR-ORG-07 | 操作审计：组织架构调整、人员增删改、角色授权均记录操作日志（操作人、时间、内容、IP）。 | P1 |

## 6. 验收标准（摘要）

1. 第 3 章全部 P0 需求逐项验证通过，P1 需求按合同约定比例通过；本版新增模块 FR-PRAC（日常练习）与 FR-NOTIFY-WX（微信通知）的 P0 条目全部验证通过。
2. 本期正式考试场景专项验证：每套试卷 20 题单选、每题 5 分、满分 100；随机抽题组卷且每人题序与选项顺序双重随机；默认限时 10 分钟且可配置；提交后自动评分即时显示成绩；考后可查看逐题正误与解析回顾。
3. 日常练习验证：不受考试时间限制、可按制度法规分类练习、可全库随机抽题、作答后即时显示答案与解析、练习记录完整留存。
4. 微信通知验证：考试发布、考前/截止提醒、成绩公布四类通知经微信通道正确触达，未订阅/推送失败时站内信兜底，发送留痕可查。
5. 并发压测：5000 人同场在线答题，答题保存接口 P95 响应 ≤ 500ms，无答案丢失。
6. 分层级统计与分数段/等级统计结果与明细数据 100% 一致（抽样核对）；个人排名按分数降序、同分按用时升序规则抽样核对一致；单位排名（FR-STAT-10）按所属单位平均分降序规则抽样核对一致，且排名范围与数据权限隔离规则验证通过；成绩明细 Excel 导出内容与库内数据一致。
7. 断线续考、倒计时自动交卷、切屏超限处理等考试关键场景专项测试通过。
