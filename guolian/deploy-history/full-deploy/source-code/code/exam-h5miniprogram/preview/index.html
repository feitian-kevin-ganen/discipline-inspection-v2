关于本预览页

本页面在浏览器中模拟微信小程序的运行外观：手机框内的内容区通过 iframe 加载 H5 考生端 http://10.110.40.160:6001/， 与真实小程序中 <web-view> 组件加载的是同一个应用。

小程序壳子源码

位于 miniprogram/ 目录（与本 preview 目录同级），采用原生 web-view 方案。

导入微信开发者工具

  1. 打开微信开发者工具，选择「导入项目」。
  2. 项目目录选择 miniprogram/。
  3. AppID 使用测试号（项目已配置 touristappid）。
  4. 在「详情 → 本地设置」中勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。
  5. 编译后首页即通过 web-view 加载 H5 考生端。

正式发布注意

  1. H5 需部署到 HTTPS 域名。
  2. 在小程序管理后台「开发管理 → 开发设置 → 业务域名」配置该域名并完成校验。
  3. 修改 pages/index/index.js 中 h5Url 为正式地址。
