## 1. 引言

### 1.1 编写背景

为加强国有企业集团纪检监察队伍建设，落实纪检监察干部教育培训与能力考核要求，集团总部需要一套覆盖"集团总部 → 二级集团 → 子企业"多级组织的在线考试系统，对全集团各级纪检人员开展常态化学习、统一考试与分层级考核统计，实现"以学促考、以考促学"的闭环管理。

### 1.2 编写目的

本文档描述在线考试系统的全部用户需求，作为后续概要设计、详细设计、数据库设计、接口设计、开发实现与验收测试的依据。

### 1.3 适用范围

- 使用单位：集团总部纪检监察部门、各二级集团、各级子企业的纪检监察机构。
- 使用人员：集团总部管理员、二级集团管理员、子企业管理员、全体纪检监察人员（考生）、阅卷人员。

### 1.4 术语定义

| 术语 | 说明 |
| --- | --- |
| 大集团/总部 | 集团总部层级，组织架构树的根节点 |
| 二级集团 | 总部直接下属的产业集团/事业部层级 |
| 子企业 | 二级集团（或更低层级单位）下属的企业单位，层级可向下延伸 |
| 考生 | 被纳入考试范围的纪检监察人员 |
| 场次 | 一次具体安排的考试活动（含试卷、时间、人员范围） |
| 固定卷 | 所有考生使用同一份试卷 |
| 随机卷 | 按抽题策略从题库随机组卷，考生试卷各不相同 |
| 等级 | 按分数段划分的成绩等级（优、良、中、差），可配置 |

## 2. 项目概述

### 2.1 建设目标

建设覆盖"学、练、考、评、统"全生命周期的在线考试平台：

1. **组织到人**：维护多级组织架构与纪检人员信息，支持按层级授权管理。
2. **学习在线化**：学习资料在线发布、在线学习、学习过程留痕。
3. **考试全流程在线化**：题库建设、组卷、下发、在线答题、自动判分、主观题阅卷。
4. **统计分层级**：按组织层级汇总考试结果，支持分数段分布、优良中差等级统计与横向对比。

### 2.2 用户角色

| 角色 | 说明 | 主要功能 |
| --- | --- | --- |
| 超级管理员 | 系统运维方/总部最高权限 | 系统参数、全部数据、账号管理 |
| 总部管理员 | 集团总部纪检监察部门管理员 | 全集团组织、人员、题库、考试、统计 |
| 二级管理员 | 二级集团管理员 | 本集团及下属子企业的组织、人员、考试组织、统计查看 |
| 子企业管理员 | 子企业管理员 | 本单位人员维护、学习/考试组织、本单位统计 |
| 阅卷教师 | 指定的主观题阅卷人员 | 主观题评阅 |
| 考生（纪检人员） | 各级单位纪检监察人员 | 在线学习、在线考试、查看本人成绩 |

### 2.3 业务全景与全生命周期流程

```
组织与人员初始化 → 学习资料建设与发布 → 纪检人员在线学习 → 学习统计（时长/内容/完成度）
      → 题库建设与题目设计 → 试卷设计（固定/随机组卷、分数设计） → 考试场次创建与考题下发
      → 在线考试（倒计时、防作弊、断线续考） → 自动判分 + 主观题阅卷 → 成绩发布与等级评定
      → 分层级统计分析（分数段、优良中差、单位排名） → 结果归档与补考/复训（闭环）
```

### 2.4 系统边界

- 系统内：组织人员管理、学习管理、题库/试卷/考试管理、判分阅卷、统计分析、系统管理。
- 系统外（仅预留对接）：统一身份认证（SSO）、企业微信/短信通知、集团 HR 组织主数据同步。本期以系统内功能为主，对接以接口预留方式实现。

## 3. 功能需求

> 需求编号规则：FR-模块-序号。优先级：P0 必须实现，P1 重要，P2 增强。

### 3.1 FR-ORG 人员组织架构管理

| 编号 | 需求描述 | 优先级 |
| --- | --- | --- |
| FR-ORG-01 | 支持多级组织架构树维护：集团总部为根，下设二级集团，二级集团下设子企业，子企业可继续下设下级单位，层级不限（建议不超过 6 级）。支持新增、编辑、停用、排序、合并/调整归属。 | P0 |
| FR-ORG-02 | 每个组织节点维护：单位名称、单位编码（唯一）、单位类型（总部/二级集团/子企业/部门）、上级单位、负责人、联系电话、排序号、状态。 | P0 |
| FR-ORG-03 | 人员管理：维护纪检人员姓名、工号（唯一）、手机号、性别、所属单位、职务、角色、账号状态。人员归属单位变更时保留其历史学习与考试记录（记录按当时单位快照留存）。 | P0 |
| FR-ORG-04 | 支持 Excel 模板批量导入组织与人员，导入前校验（重复工号、单位不存在、格式错误），导入结果反馈明细（成功/失败及原因）。 | P0 |
| FR-ORG-05 | 角色权限管理：按角色分配功能权限与数据权限。数据权限按组织层级隔离——本级管理员仅可管理本节点及下级节点的数据，上级可查看下级数据，下级不可见上级数据。 | P0 |
| FR-ORG-06 | 账号管理：初始密码生成与强制修改、密码重置、账号锁定/解锁、登录日志。 | P0 |
| FR-ORG-07 | 操作审计：组织架构调整、人员增删改、角色授权均记录操作日志（操作人、时间、内容、IP）。 | P1 |

### 3.6 FR-PAPER 试卷与分数设计

| 编号 | 需求描述 | 优先级 |
| --- | --- | --- |
| FR-PAPER-01 | 组卷方式一·固定卷：人工从题库选题组成固定试卷，逐题设定分值，卷面总分自动汇总校验（默认 100 分，可配置）。 | P0 |
| FR-PAPER-02 | 组卷方式二·随机卷（抽题策略）：按题型 + 题库分类 + 难度配置抽题规则（如：单选 20 题×2 分，其中易 8/中 8/难 4），考生进入考试时按策略实时或预生成随机试卷；支持设置全考生同卷或一人一卷。 | P0 |

| FR-PAPER-04 | 等级设置：按分数段配置等级，默认：优 [90,100]、良 [80,90)、中 [60,80)、差 [0,60)；等级名称、区间边界可自定义，区间必须连续且覆盖 0~满分。 | P0 |
| FR-PAPER-05 | 试卷管理：试卷预览、复制、封存（已被考试引用后不可修改，只能复制新版本）。 | P0 |
