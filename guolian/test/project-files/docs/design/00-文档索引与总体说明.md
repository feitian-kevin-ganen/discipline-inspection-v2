## Harness 思想落地说明

本系统设计采用 Harness 流水线式工程思想（Pipeline–Stage–Step）：

1. **业务全生命周期即流水线**：学习 → 题库建设 → 组卷 → 下发 → 考试 → 判分 → 阅卷 → 统计，各环节为独立 Stage，Stage 内由可插拔 Step 组成（如判分流水线：客观题判分 → 填空复核 → 主观分合成 → 等级评定）。
2. **声明式配置**：抽题策略、等级规则、分数段、防作弊阈值等均声明式配置，调整不改代码。
3. **组件化可插拔**：后端按业务域拆分模块，Step 级扩展点（判分器、统计口径、通知渠道）可插拔替换。
4. **自动化驱动**：自动判分、统计预聚合、定时任务（到时收卷、成绩发布）由调度流水线自动执行，关键节点审计留痕。

具体落地设计见《01-概要设计说明书》第 2、5 章及《02-详细设计说明书》判分流水线章节。
