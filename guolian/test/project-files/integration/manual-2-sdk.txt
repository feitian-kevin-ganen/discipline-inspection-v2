4.   错误码
分为网关结果码和http状态码，http状态码为ApiResponse中的responseCode的值，网关结果码为
ApiResponse的headers中X-Sofagw-Result-Status的值，一般通过网关结果码查询具体的错误原因，
判断是网关侧报错还是服务端报错
